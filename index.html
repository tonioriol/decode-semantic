01 / search

Search

The engine, a Rust port of Semble. The semantic-search plugin gives the agent this search over your code; memory uses it to find notes.

  1. Index

    Splits code along its syntax and embeds each chunk with a small model on your CPU. Edits are picked up on the next search.

  2. Rank

    Fuses keyword and vector search, so exact names and plain questions both work.

  3. Answer

    Returns file, line and snippet instead of whole files.

    03 / install

    Install

    Claude Code plugin

    Memory brings code search with it.

    # once
/plugin marketplace add tonioriol/decode-plugins
/plugin install memory@decode-plugins

    Codex plugin

    Install both by name.

    codex plugin marketplace add \
  tonioriol/decode-plugins
codex plugin add semantic-search@decode-plugins
codex plugin add memory@decode-plugins

    Search only: install semantic-search@decode-plugins. OpenCode and Cursor: see the README. macOS or Linux (Windows through WSL); needs Bash, curl and Python 3, and Git, jq and ripgrep for the hooks.
